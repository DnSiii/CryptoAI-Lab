# V99 R106 — preregistered 2022-01-23 Deribit trade-tape pagination feasibility (2026-10-30)

**TRAIN SOURCE-ONLY, NOT AN ENGINE, NOT EXECUTABLE BBO, NOT AN I1 APPROVAL.** This bounded experiment tests whether the already independently verified first-party public trade endpoint can furnish a *complete API-paginated target-day trade activity tape* for both currencies, and whether the target-day tape contains trade activity in 28–35d put expiries. It cannot replace 24/24h two-sided order books, native fees, funding, marks, fills, or a licensed archive.

Preselect exactly **2022-01-23 UTC** for BTC and ETH, before the original fixed **2022-01-24 00:00 UTC** I1 decision; no other date and no post-2023-10-01 read. Endpoint: `https://history.deribit.com/api/v2/public/get_last_trades_by_currency_and_time`, `kind=option`, `include_old=true`, `sorting=asc`, `count=1000`. Start at UTC midnight, end at 23:59:59.999. Continue with `start_timestamp=last_returned_timestamp` (inclusive overlap) and de-duplicate only by original trade_id; reject conflicting duplicate IDs, non-advancing pages, timestamps outside the day, malformed options, non-positive trades and out-of-order rows. **64 pages maximum per currency**, maximum **4 MiB raw response per page**, at most **3 transport attempts per page**. Stop only on authenticated `has_more=false`; page cap, rate limit, missing IDs or timestamp tie deadlock => **INCOMPLETE/UNKNOWN**, never "no market". If the API has a timestamp-tie pagination limitation, explicitly disclose it.

Original page bytes remain ephemeral in CI; each page's SHA256, count, time span, overlap and original ID evidence is independently re-parsed by a separate oracle before deletion. Publish only aggregate counts, unique contracts/strikes by side, distinct eligible 28–35-day **put** strikes (expiry relative to 2022-01-24 UTC), day start/end observed, pagination status, and digests. No raw trade rows in artifacts or public dashboard. Trade activity on two strikes across a day **does not imply a synchronized two-strike executable spread**. The independent oracle must reject any forged completeness, non-original page digest, duplicate conflict, fake quote/fill flag, or unauthorized promotion.

Decision: if both streams end with `has_more=false` and pass independent byte-level checks, `PUBLIC_TRADE_DAY_PAGINATION_COMPLETE_NOT_QUOTES`; otherwise `PUBLIC_TRADE_DAY_PAGINATION_INCOMPLETE_OR_UNKNOWN`. Both are **I1 SOURCE HOLD, NO PROMOTION**, 0/180 certified lifecycles. No economic backtest, ROI, validation, holdout, paper or orders. Frozen V16/V99 and champion immutable. Critical blocker remains original licensed 661-day BTC+ETH 24h two-sided options quotes/depth/arrival/marks/settlement and dated fees, with 658 missing quote days, independently verified costs/fills, 5-fold TRAIN and gates.

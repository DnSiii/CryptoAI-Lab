# V99 I1 — real public full-day Deribit OPTIONS source smoke (pre-implementation, 2026-10-28)

**Purpose:** exercise the actual 661-day importer against one *real*, freely published first-of-month Tardis Deribit OPTIONS quotes day, not just mock CSVs. Tardis documents first days of each month as public and archives by **arrival** day. This is an engineering smoke test only; one day cannot authenticate a complete 661-day TRAIN, legal historical grant, native fee/lot/margin/delivery terms, fills or economic returns.

**Ex-ante fixed request:** exactly `2022-06-01`, `https://datasets.tardis.dev/v1/deribit/quotes/2022/06/01/OPTIONS.csv.gz`, unauthenticated HTTPS GET; no dynamic date or contract selection. Bounded 512 MiB compressed, <= 180 seconds network read, never touch 2023-10-01 onward. Stream to temporary local file, reject non-200, HTML/JSON, non-gzip, oversized, truncated, corrupt or invalid original day. Run existing `scan_day` on the entire gzip only if fully downloaded; hash and summarize counts, without publishing rows or storing archive artifacts. If too large, explicitly report `BOUNDED_REAL_SOURCE_INCOMPLETE`, never call it a full-day pass.

**Acceptance:** offline mocked tests prove complete genuine-format gzip can pass and produce source-only metrics; truncated, missing-asset, wrong-day, over-cap and non-gzip responses fail closed; exact URL and zero credentials/validation/holdout access. GitHub push CI actually attempts public real-day retrieval and records result; any unavailable external network or size limit is a documented blocker, not a fake pass. No raw licensed bytes committed, uploaded or used for economic TRAIN. Frozen, paper, champion and sealed periods unchanged. **NO PROMOTION/NO ORDERS.**

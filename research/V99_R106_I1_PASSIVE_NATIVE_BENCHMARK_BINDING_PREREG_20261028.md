# V99 I1 — preregistered passive-native benchmark binding (2026-10-28 04:xx BRT)

Scope: strictly existing 661-day TRAIN accounting bridge only; no strategy retune, no new alpha, no validation/holdout, no original source claim. This is a correctness fix for the existing numeric benchmark gate.

**Observed defect before change:** `v99_r106_i1_native_event_equity._run_scenario` reads `benchmark_usd` directly from an event-journal row and checks only positivity. Thus a caller can claim a flat or deliberately low benchmark while holding BTC+ETH coin collateral whose USD value rises with the input index. The `original_benchmark_excess` gate may then reward passive coin exposure rather than genuine option strategy excess, even on a synthetic 661d test. A flat benchmark fixture masks the defect.

**Fixed rule (no tuning):** derive a mandatory self-financing passive BTC+ETH benchmark from exactly the same initial BTC and ETH native wallet balances and each daily original BTC/ETH USD index already supplied for NAV: `benchmark_usd = initial_coin['BTC']*index_usd['BTC'] + initial_coin['ETH']*index_usd['ETH']`. If an event row supplies `benchmark_usd`, require numeric exact equality to this derived value; reject mismatches. Emit the derived value, not caller-provided benchmark. Use the same rule for severe/supersevere; keep strict source-index path matching. No source-index provenance is thereby certified. This is the **passive native-collateral benchmark**, not a universal BTC/ETH market envelope; other independent benchmarks remain required before promotion.

**Predetermined controls:** (1) existing constant-index synthetic 661d tests stay green; (2) a varying BTC/ETH index synthetic 661d series must produce the independently calculated passive benchmark on every day in both scenarios; (3) a forged low benchmark must fail; (4) a forged high benchmark must fail; (5) nonfixture official economic gate must remain BLOCKED. No attempt to make an alpha candidate pass gates. No trading orders or protected-file modifications.

**Decision:** fix accounting benchmark integrity regardless of its effect on numeric synthetic ROI. All original historical economic metrics remain unavailable until lawful 2021–2023 BTC+ETH options BBO/sizes/venue+arrival timestamps, historical native fees, margins, delivery/settlement and independent fills are actually authenticated.

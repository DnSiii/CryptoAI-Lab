# V98 Independent BX — preregistered segregated four-book compounding engine (2026-10-24; before BX PnL)

## Structural hypothesis (distinct from rejected BR–BW)

Frozen BW post-rejection forensic evidence found that leave-one-sleeve-out ablations changed **BTC/ETH core exposure** via shared authorization/ratchets; it also found capital-capacity collapse at USD10m. BX changes the *accounting and physical execution architecture*, not a rejected strategy's thresholds. Four **segregated, non-cross-collateralized virtual books** have fixed initial cash partitions [65%, 15%, 10%, 10%] and never transfer wealth. Each book reinvests its own realized NAV; an omitted book stays in cash. This guarantees that core positions cannot be altered by the existence of a satellite, so full-minus-ablation marginal growth reflects sleeve wealth rather than changed core exposures. Aggregate execution is the conservative sum of independently paid gross fills, **no internal netting discount**. Each book gets only 25% of observed prior-hour quote and exit-window capacity; four-book total cannot invent participation.

## Seven complete slots

1. **Growth Core:** all four Clean-4 assets eligible; at completed 336h epochs, choose up to two assets with positive 672h log momentum ranked by 672h trend divided by 336h realized hourly volatility; allocate long by positive risk-adjusted score. If none eligible, cash. This is an all-asset cross-sectional momentum rotation, not BW's BTC/ETH slow trend.
2. **Opportunity Sleeve:** causal 168h close breakout over prior 168 completed closes, with 168h trend > 8% and 24h momentum > 1%; choose strongest 168h volatility-normalized breakout, hold 168h; no intrahold retune. Long-only convex continuation.
3. **Relative-Value Sleeve:** every 336h, long the asset with the *lowest* prior 336h native signed funding and short the asset with the *highest*, dollar-neutral 50/50, only if spread > 0.5% per 336h and the long asset's 168h return is no more than 10% worse than the short asset. This is native carry dispersion rather than BW SOL/BNB trend pair.
4. **Stress/Recovery Sleeve:** at 168h epochs, if cross-asset median 72h log return < -8%, short the two weakest 72h assets equally; otherwise, if median 168h log return < -15% and median 24h log return > +4%, long two strongest 24h recovery assets. Otherwise cash.
5. **Regime Router:** completed-close BULL when median 336h return > 8% and 168h cross-sectional breadth positive >=3; CRISIS when median 72h return < -8%; else NEUTRAL.
6. **Dynamic Allocator:** fixed cash partitions but state-dependent **within-book** gross budgets: Core BULL/NEUTRAL/CRISIS 1.5/1.1/0.4, Opportunity 1.4/1.0/0.0, RV 0.8/0.8/0.5, Stress 0.0/0.0/1.0; each additionally scales by 336h realized volatility using min(1,0.015/max(0.005, median vol)). A satellite is only signaled on its own epoch. No realized-PnL feedback, cross-book transfers, or retrospective selection.
7. **Risk Governor:** four independently funded V98 physical governors, each with 25% of the same authenticated *prior-hour* quote and 336h minimum 24h-exit-window capacity, native signed funding reserves, staged stress, real opening fills, 81-corner intrabar settlement. Physical aggregate gross fills are summed without netting; no future quote, hidden borrowing, or external market-data dependencies.

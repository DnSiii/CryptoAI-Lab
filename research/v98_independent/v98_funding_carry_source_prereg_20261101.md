# V98 Independent — signed native funding-carry source feasibility preregistration (2026-11-01)

**Pre-result, no strategy or PnL.** The existing full masked spot/perp basis diagnostic already rejected naive basis convergence as a demonstrated executable edge. This experiment is economically different: it tests whether *signed exchange-native funding receipts* could, even before basis drift and hedge frictions, cover fixed round-trip fee budgets for a constant 1:1 long-spot/short-perpetual hedge. Do not promote this diagnostic or alter prior rejected engines.

**Immutable source and population.** Only four Clean-4 symbols BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT and exposed calendar 2025, never 2026+, XRP, old contaminated holdout, external benchmarks, Frozen or paper. Reuse the pinned NH official USD-M 2025 artifact and its original funding CSV SHA256 per symbol, alongside the already validated 2025 spot/perp calendar. Check all 1,095 8-hour funding slots per asset, 4,380 events total, strict UTC 00/08/16 slot sequence, exact source receipt SHA and every source CSV SHA. No interpolation, missing-event repair, sign reversal, optimization or source substitution.

**Fixed calculation, no fitting or selection.** Partition 2025 into its 12 fixed UTC calendar months, all 4 assets = 48 asset-month windows, with no lookahead-dependent selection. For each asset-month calculate signed sum of observed funding rates, multiplied by 10,000 to express bps of constant nominal short-perpetual exposure; positive funding is a receipt for the short, negative is a payment. Report monthly signed sum, event count, number of positive/negative months, and counts whose signed funding exceeds **30/50/70 bps**. The 30-bp value is an illustrative published regular taker four-fill spot+USD-M round-trip nominal fee budget (spot 2x10 + perp 2x5 bps); 50/70 bps are fixed stress budgets, **not historical account fees**. Compare signed carry with each budget but never relabel it PnL, arbitrage, net return or CAGR. No compounding, basis convergence, position rebalancing, mark-to-market, fees actually debited, spread, slippage, borrow, collateral, liquidation, tax or future funding forecast.

**Implementation and independent checks.** Produce canonical source-event CSV with source CSV SHA per event, SHA256 receipt, 48 Decimal monthly signed sums and 3 fixed budget comparisons. A separate read-only Decimal oracle independently replays all source events from the canonical output, checks chronological order, sums, source hashes and all fee-budget counts; exercise deliberate receipt and event tampering. Reuse existing V98-only source-diagnostic workflow without modifying any workflow, frozen engine, branch or paper. Any source/audit failure rejects the diagnostic.

**Decision boundary.** This source-only test can *eliminate* the naive funding-carry economic premise if even gross signed funding fails illustrative budgets, but passing cannot establish executable edge: the entry/exit basis path, hedge funding notional, actual account fee schedule, spot borrow/short availability, bid/ask/depth, financing, liquidation and exact 13,524 funding settlement marks are not verified. No candidate promotion, paper/live authorization or holdout access. A new seven-slot complete V98 would still need a separate preregistered mechanism and physical historical execution before validation.

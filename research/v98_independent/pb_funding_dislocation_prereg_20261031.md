## Economic hypothesis
Persistently crowded long exposure (positive native funding) is less attractive than similarly trending, less crowded exposure; funding pressure can reveal a differential source of growth and conditional squeezes. Native historical funding **rates** are checksum-authenticated; exact funding-event `markPrice` is **not** and conservative signed 1h mark envelopes remain settlement sensitivities. Rates at current decision time must use **previous settled events only**; no current/future funding in signals.

## Frozen seven-slot system
1. **Growth Core:** at weekly close t, compute 672h, 168h, 24h log returns and arithmetic mean of the 21 settled 8h funding rates at t-168,...,t-8. Score = r672 + 0.65*r168 - 120*meanFunding. Risk-on if >=3 assets have positive r168 and BTC r168>0: long top two *positive-score* assets +0.50/+0.18 NAV. Risk-off if >=3 negative r168 and BTC r168<0: short bottom two *negative-score* assets -0.42/-0.20 NAV. Otherwise long best positive-score asset +0.35 if its r168>0, or short worst negative-score asset -0.30 if r168<0; else cash. Ties by symbol index.
2. **Opportunity:** among alts, mean funding < -0.00005, 24h return > +0.04, 168h return >0: long best 24h return +0.20. Else if mean funding > +0.00015, 24h return < -0.05, 168h return <0: short worst 24h return -0.20. Otherwise cash.
3. **Relative Value:** among alts, long lowest-funding and short highest-funding at +0.12/-0.12 if funding spread >0.00015, their 168h relative return (low minus high) >0.04, and the long leg's 168h return>0. No market beta assumption; market-neutral not guaranteed in gaps.
4. **Stress/Recovery:** if BTC r168 < -0.10 and >=3 assets have negative r168, short BTC -0.18. Else if BTC r168 < -0.10, BTC r24>0.035, >=3 assets positive r24, long BTC +0.18. The first branch has priority; no lookahead.
5. **Regime Router:** risk_on/risk_off/mixed as above. Optional multipliers: risk_on (1,1,0.50), risk_off (0.50,0.75,1), mixed (0.75,1,0.75), order Opportunity/RV/Stress.
6. **Dynamic Allocator:** Core first, optional aggregate <=0.30 NAV, total virtual gross <=0.88 NAV. Optional priority risk_on=(Opportunity,RV,Stress), risk_off=(Stress,RV,Opportunity), mixed=(RV,Opportunity,Stress). Every ablated book reallocates independently with same rules.
7. **Risk Governor:** unchanged V98 OT one-way physical planner (not its alpha), t+1 open, signed worst-side hourly official mark OHLC funding envelope, zero-volume no-fill, adverse OHLC intrabar checks, fee/slippage pre-funding, safety fills, hard gross limits. Base 4+2 bps, severe 10+10 bps, supersevere 15+20 bps. Funding order carried-before-fill and new-after-fill.

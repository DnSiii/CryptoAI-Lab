# V98 Independent JA — joint posterior log-growth allocation, preregistered 2026-10-27

**LOCKED BEFORE IMPLEMENTATION, NATIVE SOURCE GATES OR SYSTEM PNL.** JA is a new *joint posterior optimization* architecture: each of three sleeves contributes a distinct causal expected-return forecast to a single constrained portfolio, rather than competing for fixed sleeve budgets or using IZ's historical online-shadow eligibility. It does **not** reuse, modify, rescue or promote any rejected engine (IM–IZ). Earlier rejected observations motivate a portfolio-level hypothesis, not calibration of parameters.

## Fixed training universe and chronology
Only pinned, authenticated native Binance USD-M Clean-4 (BTC, ETH, BNB, SOL), Dec-2022 warmup, 2023 and 2024 chronological training. All OHLC, quote, signed native funding/event, mark/settlement checks. No 2025 until training candidate frozen; no 2026+, XRP, Phase083, V14/V15/V99 internals, Frozen or paper. ## Seven required slots
1. **Growth Core**: 672h signed-funding-adjusted log momentum per hour, centered at cross-asset median; prior 672h hourly volatility. Core's long-only reference is normalized positive 672h net log growth divided by volatility, falling back to inverse volatility if all are nonpositive.
2. **Opportunity**: cross-asset 48h acceleration versus the preceding 120h, with quote participation ratio of last 48h versus prior 168h. Predictive vector = centered acceleration per hour times clipped [0.5,1.5] quote ratio; no event-selected sign rescue.
3. **Relative Value**: 168h asset return residual versus the 4-asset median, divided by 168h, de-meaned. This is a forecast, not a separately financed fixed dollar-neutral book.
4. **Stress/Recovery**: regime-dependent downside asymmetry: STRESS penalizes assets with largest 168h downside semideviation; RECOVERY rewards assets with strongest 48h rebound from 168h drawdown; NORMAL rewards lowest downside semideviation. Each vector centered, never independently chosen by post-result PnL.
5. **Regime Router**: STRESS if median 168h log return <0 and median 168h/672h volatility ratio >1.15; RECOVERY if median 48h return >0 and median 168h drawdown <-0.05; otherwise NORMAL.
6. **Dynamic Allocator**: fixed shrinkage forecast `mu = 0.65*core + 0.15*opportunity + 0.12*relative_value + 0.08*stress` (all per-hour, centered, clip each to +/-0.002). Compute a 672h covariance with diagonal 0.0001 ridge. Solve one deterministic quadratic Kelly-surrogate `w*=inv(8*cov + 0.0004*I) @ mu`, apply a turnover-aware blend `w = 0.65*previous_target + 0.35*w*`, then sign-preserving per-asset cap 0.60 and L1 gross cap 1.00. Add a 0.15 long-only Core reference before projection to avoid all-cash degeneracy; normalize to gross 1 when feasible. All four forecasts compete jointly under the same gross limit; no sleeve cash subsidy, fixed optional allocation, online-shadow performance gate, or hidden leverage. For each leave-one-sleeve-out physical ablation, **recompute the full optimization** with its forecast removed, reweight remaining fixed coefficients to sum 1, and use an independently funded USD10k ledger. This is a prespecified model counterfactual, not post-result refit.
7. **Risk Governor**: existing prior-only physical margin/exit governor with gross targets NORMAL 1.0, STRESS 0.85, RECOVERY 0.95, actual next open and intrabar mark settlement, native funding, base/severe/supersevere fees and slippage, both funding orders. Independent cash conservation and no hidden borrowing.

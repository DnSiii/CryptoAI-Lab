## Seven slots — causal, single hypothesis, no grid
1. **Growth Core**: slow 672h positive-trend / inverse-volatility allocation: compute each asset's 672h closed-close log momentum minus native signed paid funding and a volatility penalty (0.5 times 672h hourly std times sqrt(672)); allocate to positive scores only with square-root score weights; if none positive, use equally weighted long BTC/ETH/BNB/SOL. No hindsight top-performing asset selection.
2. **Opportunity**: long the single asset with strongest 168h risk-adjusted breakout, defined as current completed close / prior 336h completed-high maximum minus one, divided by max(168h hourly std, .002). Only active if the score is positive; otherwise zero exposure.
3. **Relative Value**: price-neutral cross-asset dispersion: 336h *residual* log return after subtracting cross-asset median return, divided by 336h downside deviation floor .002. Long highest, short lowest, half gross each. No funding-spread pair ranking (distinct from IY).
4. **Stress/Recovery**: volatility compression breakout: if median 168h log return <0 and median 168h vol / 672h vol >1.25, short the most negative 168h return; if median 168h return >0 and median 168h vol / 672h vol <.85, long the strongest 168h return; else long the lowest 168h downside deviation. Different state and selection from IY.
5. **Regime Router**: STRESS and RECOVERY defined in slot 4; NORMAL otherwise. Deterministic t-1 only.
6. **Dynamic Allocator**: **causal online shadow marginal wealth**. For each optional sleeve, compute trailing 672h shadow log wealth against Core, using prior 336h epoch-held signed target exposure, actual historical hourly close-to-close price and native signed funding. Subtract 0.0008 of estimated turnover on every shadow rebalance, plus 0.00015 per elapsed 24h as friction reserve. A sleeve qualifies only if its *strictly prior* 672h shadow log wealth minus Core is >0.01 and has at least 2 prior epoch observations. Allocate Core 0.55 and split the remaining 0.45 among qualifying optional sleeves proportional to clipped [0.01,0.10] shadow edge. If none qualify, Core gets 1.00. This is an online causal gate, NOT a hindsight historical ablation or tuning against 2023/24 results. Missing/invalid quotes quarantine optional sleeves and finance Core.
7. **Risk Governor**: independently existing prior-only buffered physical governor, 1.0 target gross NORMAL, .8 STRESS, .95 RECOVERY, native physical settlement, no hidden leverage, independent USD10k books for Full, Core-only, and three minus-sleeve counterfactuals.

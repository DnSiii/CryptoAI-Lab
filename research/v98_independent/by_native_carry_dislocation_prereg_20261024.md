## Frozen test before any BY economic result
Use only PINNED original Clean-4 (BTCUSDT/ETHUSDT/BNBUSDT/SOLUSDT) 1h Dec2022–Dec2024 and 9,144 native signed funding events via V98 authenticated loader; 2025 holdout sealed, 2026+, XRP and V14/V15/V99 forbidden. From completed close at t >= 2160, every 336 hours (no grid), compute each asset's completed 336h log return and 336h *native* signed funding sum, using only events at or before t. Long candidates have log return > +0.05 and prior signed funding sum < 0 (long earns funding); short candidates have log return < -0.05 and prior signed funding sum > 0 (short earns funding). Choose one candidate with greatest absolute 336h log return, deterministic asset-order tie break; otherwise cash. Do NOT select on future price or realized PnL. No overlapping episodes. Enter at actual t+1 OPEN and exit at actual t+337 OPEN, skipping any episode whose exit exceeds 2024-12-31. The future price is used solely for retrospective evaluation, never signal selection.

Per one USD entry notional, signed realized price PnL = side*(exit_open/entry_open - 1); native funding cashflow = sum of -side*rate*event*conservative_mark/entry_open at funding timestamps between entry and exit (exclusive of exit); conservative mark is HIGH if side*rate>=0 else LOW. Roundtrip fees+slippage are (entry_notional+exit_notional)*(fee+slip), with BASE 0.001, SEVERE 0.005, SUPERSEVERE 0.015 per side from the existing V98 cost contract. Also record worst actual intrahold high/low excursion; do not infer intra-hour liquidation from episode return. For source-only capacity, use the frozen prior 336h minimum contiguous 24h quote volume, with existing ENTRY_FRACTION, PARTICIPATION, STRESSED_QUOTE_FRACTION and EXIT_FRICTION_MULTIPLIER; report USD capacity, never assume fills or relax the constraint.

## Falsification / advancement rule
The mechanism is eligible for an independent seven-slot architecture preregistration **only if** >=4 selected episodes with entry in each of 2023 and 2024 AND the **sum of severe net per-USD episode returns** is strictly positive in **each** calendar entry year; base and supersevere, worst excursion, number of episodes, funding-vs-price contribution, and per-asset capacity must all be reported, not optimized away. If it fails, permanently reject this BY mechanism without sign/window/threshold/funding rescue. If it passes, this is merely a source-level prerequisite: no engine approval, no extrapolation of unit returns to CAGR, no 2025 validation or comparison with external engines until a separate complete engine is preregistered, frozen and independently validated.

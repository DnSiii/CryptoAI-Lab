# V98 Independent IM — causal cross-asset shock-transmission portfolio (2026-10-27)

**Immutable, before code/economic inspection.** IM is a *new complete seven-slot architecture*, based on empirically estimated conditional 72h transmission after 24h cross-market price shocks. At completed close t, every 72h from t=744, use only information <=t; trade at actual open t+1. Fixed BTC/ETH/BNB/SOL ties. Strict source positivity, zero quote quarantine and t+1 future mutation test. No hypothetical fills or synthetic funding.

Define for each completed hour s the cross-market 24h return M_s=median_i log(C_i,s/C_i,s-24). At decision t use historical shock observations s in [t-672,t-72], so their realized 72h forward returns and funding are fully known by t. A shock threshold H_t=2*median(abs(M_s)) for the same historical interval (strict >0). Historical signed state: DOWN M_s< -H_t, UP M_s>H_t, NORMAL otherwise. **No forward label from s>t-72.** For each state and asset compute the equal-weighted mean of the *realized native-funding-adjusted* 72h log return log(C_s+72/C_s) minus sum native signed funding events s+1..s+72. Require >=12 historical samples per chosen state, otherwise no optional exposure and Core receives budget. Current state uses M_t against H_t. Conditional estimates are a causal descriptive forecast, not guaranteed future edge.

## Seven slots
1. **Growth Core**: always long 4 assets, weights proportional to sqrt(mean prior 336h native quote volume), normalized. No borrowed capital.
2. **Opportunity**: only if current state UP or DOWN, valid state sample count>=12 and max forecast > +0.012, long the single asset with maximum estimated 72h net return. Else CASH.
3. **Relative Value**: if valid state sample count>=12 and max-min conditional *asset minus equal-asset mean* 72h forecast > +0.018, long 50% best and short 50% worst. Else CASH.
4. **Stress/Recovery**: valid DOWN state => short asset with minimum conditional forecast if its forecast < -0.012; valid UP => long asset with max forecast if >+0.012; valid NORMAL => long asset with best estimated forecast if >+0.012. Else CASH. This is an asymmetric shock-response *conditional* exposure, not an IL candle-rejection signal.
5. **Regime Router**: STRESS for DOWN, RECOVERY for UP, NORMAL otherwise.
6. **Dynamic Allocator**: state budgets Core/Opp/RV/Stress: STRESS [0.45,0.20,0.15,0.20], RECOVERY [0.40,0.25,0.15,0.20], NORMAL [0.62,0.10,0.18,0.10]. Inactive or ablated budget funds Core. Gross requested STRESS 0.80, RECOVERY 0.98, NORMAL 0.90. Fixed **before results**, no leverage increase after results.
7. **Risk Governor**: prior-only GL 81-corner buffered authorization with realistic staged exits, fees/slippage, native signed funding, both funding order conventions, USD10k independent cash book per ablation.

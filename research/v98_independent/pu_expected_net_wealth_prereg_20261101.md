## Deterministic forecast, no training fitting
Let log close p, hourly returns h_k=p_k-p_(k-1). On last 336 completed hourly returns (k=t-335..t), fixed exponential weights w_k proportional to 2^(-age/168), normalized. Expected hourly log return mu=sum(w*h); covariance = 0.5 weighted empirical covariance + 0.5 its diagonal (PSD shrinkage); v_j=diagonal covariance. For each asset native funding expectation f_j = arithmetic mean of the last **21 observed 8-hour rates** at t-160,t-152,...,t, divided by 8 to express hourly long cost. These are historical observations only, not oracle future funding. Horizon H=168 hours. Forecast net log utility of net target x relative to previous *target* net inventory x_old:
U(x)=H*(dot(x,mu-f)-0.5*x^T cov x)-0.0006*sum(abs(x-x_old)).
This is a heuristic forecast, NOT calibrated expected PnL. No training fit, grids, realized future outcomes or benchmark input. The 0.0006 is the precommitted 4+2 bps base round-trip change penalty; severe/supersevere are evaluated later without optimizing anew.

## Seven slots and exact policy
1. **Growth Core:** For each asset calculate best directional forecast score: H*(abs(mu_j-f_j)-0.5*v_j). Direction sign(mu_j-f_j), zero -> no position. Eligible only if score>0.015 and absolute 336h log return >=0.04 in the same direction. Rank eligible descending by score, tie by asset index; allocate 0.42 first and 0.20 second, signed. No ex-post asset selection.
2. **Opportunity:** Cross-asset *acceleration*, a different horizon than the core: a_j=(p_t-p_(t-168))-(p_(t-168)-p_(t-336)). Require abs(a_j)>=0.12, 72h quote-volume ratio vs preceding 72h >=1.20, and sign(a_j)=sign(mu_j-f_j). Select maximum abs(a_j), tie index; signed 0.16, else cash.
3. **Relative Value:** Funding-rate *spread* hedge, not price residual or spot/perp convergence: among Clean-4 choose highest and lowest f_j. If spread in 8-hour units >=0.0015, long low-funding asset +0.10 and short high-funding asset -0.10; otherwise cash. Never use future rates.
4. **Stress/Recovery:** if >=3 assets have 72h log return <=-0.10 and BTC 24h return <=-0.04, short BTC -0.14; else if >=3 assets have 72h return <=-0.08 and BTC 24h return >=+0.04, long BTC +0.14; otherwise cash.
5. **Regime Router:** broad up if >=3 assets have 336h return >0; broad down if <=1; otherwise mixed. Router affects optional evaluation tie-break only: up (Opportunity,RV,Stress), down (Stress,RV,Opportunity), mixed (RV,Opportunity,Stress).
6. **Dynamic Allocator:** Core always first; for each of 8 binary activation tuples of optional sleeves (fixed order by slot index), allocate chosen optional sleeves in regime priority, with optional virtual gross cap 0.28 and combined virtual gross cap 0.84, proportional clipping only when remaining room insufficient. Score each candidate by U(x) using **previous decision's full-book target net inventory**, not future realized fills. Choose maximum U; ties to 1e-12 prefer lower target turnover, then lower virtual gross, then smaller activation bit tuple. If maximum U is not strictly greater than core-only U by 1e-12, choose core-only. For leave-one-out books, run the same frozen optimizer with that sleeve disabled, with **their own prior target inventory state**. No hindsight or use of realized PnL to choose action.
7. **Risk Governor:** existing independently audited V98 atomic one-way net planner, pre/post fee and funding solvency, hourly adverse OHLC, zero-volume execution veto, gross and no-hidden-leverage; no modification to physical runner.

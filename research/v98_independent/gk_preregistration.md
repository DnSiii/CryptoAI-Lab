## Seven-slot locked algorithm
1. **Growth Core**: every 168 completed hours, 672h signed-funding-net close-log return and 168h hourly log-return std floored .002. Core_j proportional to max(net672_j,0)/vol168_j + .05, normalized long-only.
2. **Opportunity Sleeve — 72h risk-normalized acceleration**: rank 72h native-net return divided by 72h hourly volatility floored .002. Top asset +.60 and bottom asset -.60 in expert logit space (when distinct); expert portfolio softmax(log(core)+signed tilt). This is a short-horizon volatility-adjusted opportunity expert, not GJ residual168 or GI signed body.
3. **Relative Value Sleeve — signed funding dispersion**: 168h native funding burden. If spread>0.0005, lowest burden +.50, highest burden -.50 in expert logit space; expert softmax(log(core)+tilt). Same independently supported information family, but with causal online convex weighting rather than GJ static logits.
4. **Stress/Recovery Sleeve — downside beta resilience**: use 336h hourly log returns; basket return is equally weighted cross-asset hourly mean. For each asset beta_down = sum(min(asset_hourly_return,0)*min(basket_hourly_return,0))/max(sum(min(basket_hourly_return,0)^2),1e-9). If cross-asset beta spread>.10, lowest downside beta +.50, highest -.50 in expert logit space, then softmax(log(core)+tilt). Tests resilience/recovery convexity, not GH intrabar low, GI range expansion or GJ underwater rebound.
5. **Regime Router**: 672h signed-funding-net breadth: TREND if >=3 positive; PANIC if <=1 positive; else ROTATION. Gross requests 2.25/1.30/1.85, always bounded by unchanged physical governor.
6. **Dynamic Allocator — online convex expert mix**: For each sleeve i, define delta_i(t)=expert_i(t)-core(t) (zero sum). Before generating target at epoch t, update past-only edge_i(t)=.75*edge_i(t-168)+.25*(delta_i(t-168) dot native_net_return(t-168,t) - .001*sum(abs(delta_i(t-168)))); initialize edge=0 at first epoch. For each currently active expert, lambda_i(t)=.05+.15*sigmoid(clip(edge_i/.02,-30,30)); inactive lambda=0. Full weights = core + sum(lambda_i*delta_i), long-only convex, sum1 and sum(lambda)<=.60. Leave-one-out removes exactly one expert's convex contribution and redistributes it to core; no ex-post score or costs used in training, no separate collateral, no hidden leverage. Same online lambda sequence across ablations.
7. **Risk Governor**: same CG 60% stressed-NAV buffer, 81-corner staged exit, prior-only conservative quote liquidity, signed native funding, base/severe/supersevere fee+slippage and both funding orderings.

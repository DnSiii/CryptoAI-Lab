## Fixed signal contract
Universe: BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT, Binance USD-M 1h, pinned 2022-12-01 through 2024-12-31, native signed funding/mark bounds, no 2025 holdout, no XRP, no 2026+, no V14/V15/V99. Warmup 1008h; signal only at completed close t=1008+168k; earliest trade open t+1. All windows include t or earlier, no future returns.

1. Growth Core (every 336h): compute each asset's 1008h and 336h log returns and its last 168h signed funding-event sum. Score = 1008h log return minus 6 times the signed funding sum (long pays positive funding); eligible only when both 1008h and 336h log returns are positive. Among eligible, rank descending score, hold top one 70% and second 30%; one alone 100%; none cash. No implicit leverage.
2. Opportunity (every 168h): for BNB and SOL, compute 72h and previous 72h log returns. Eligible when last 72h >0, last 72h > previous 72h by >0.015 log points, and last 72h quote volume >= 0.8 times prior 72h. Long eligible asset with highest acceleration; else cash. This is an acceleration/volume *change* hypothesis, not CT's percentile breakout.
3. Relative Value (every 168h): compute 72h BTC log return and 72h BNB/SOL log returns. For each alt subtract 72h BTC return to obtain simple BTC-relative residual; if absolute residual difference between BNB and SOL exceeds .025, buy the underperformer 50% and short outperformer 50%. Else cash. No BTC/ETH trend pair, no native carry spread and no conditional-beta selection.
4. Stress/Recovery (every 168h): BTC trailing 336h peak-to-current drawdown = 1 - BTC close / max BTC close over t-335..t. If drawdown >= .10 and BTC 72h return > .015, long ETH 100%; if drawdown >= .10 and BTC 72h return < -.015, short ETH 100%; otherwise cash. This is a drawdown-conditioned ETH reaction, not CT's BTC continuation or CM's downside beta.
5. Regime Router: RISK_ON when >=3 positive 336h returns and BTC 336h return >0; RISK_OFF when <=1 positive 336h return and BTC 336h return <0; otherwise MIXED.

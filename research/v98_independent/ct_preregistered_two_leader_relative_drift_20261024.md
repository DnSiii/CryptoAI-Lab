# V98 Independent CT — preregistered two-leader compounding and BTC/ETH relative drift (2026-10-24)

## Independent, prospective thesis
CT tests a new **complete seven-slot engine** built around persistent two-leader compounding, liquidity-confirmed alt breakouts, BTC/ETH relative-drift capture, and asymmetric BTC drawdown/recovery. It does not inherit rejected CS funding-spread, acceleration, all-asset strength weighting or stress logic; neither rejected source signals nor any rejected parameter set is used. A satellite is judged by **annual incremental portfolio log growth**, not isolated sleeve profitability. The objective is highest sustainable CAGR subject to physical survival, not minimal risk.

## Fixed slots and causal execution
Only authenticated Clean-4 BTCUSDT/ETHUSDT/BNBUSDT/SOLUSDT Binance USD-M 1h Dec-2022 through Dec-2024, native signed 8h funding, conservative mark bounds. Warmup first 744h (Dec 2022). Completed close t, earliest next hour open t+1. Weekly decisions at t=744+168k; Growth every 336h.
1. **Growth Core:** every 336h rank four assets by trailing 336h log return, keep at most two with positive return. If two: allocate 70% notional to highest and 30% to second; if one: 100%; if none: cash. Persistent units until next Growth epoch.
2. **Opportunity Sleeve:** every 168h inspect BNB and SOL. An alt is eligible only if close t exceeds the 75th percentile of its preceding 336 hourly closes, trailing 168h return >0, and sum of quote volume over latest 168h exceeds preceding 168h. Long eligible alt with greatest price-to-prior-336h-median ratio, 100%; else cash. No short.
3. **Relative-Value Sleeve:** every 168h compare BTC and ETH trailing 336h log returns. If absolute difference exceeds 1.5%, long the stronger 50% and short the weaker 50%; otherwise cash. This captures medium-term **BTC/ETH relative drift**, not funding spread, ratio mean reversion, SOL shorts or cross-sectional four-asset spread.
4. **Stress/Recovery Sleeve:** every 168h, short BTC 100% only if trailing BTC 336h, 168h and 72h returns are all negative; otherwise long BTC 100% only if trailing BTC 168h return <0, trailing 72h return >0 and preceding 168h return <0; otherwise cash. Downtrend continuation vs delayed recovery.
5. **Regime Router:** RISK_ON if BTC 336h return >0 and >=3 of four 168h returns >0; RISK_OFF if BTC 336h return <0 and <=1 of four 168h returns >0; else MIXED.
6. **Dynamic Allocator:** fixed [Growth,Opportunity,RV,Stress] budgets RISK_ON [2.15,.35,.30,.10], MIXED [1.60,.40,.40,.25], RISK_OFF [.70,.20,.45,.65]. Persistent units; actual authorization by risk governor, no hidden leverage.
7. **Risk Governor:** unchanged generic CG buffered physical authorization with 81 intrabar stress corners, stressed reserve/floor/maintenance, 0.25% participation, staged exits, native funding and mark bounds. No tuning.

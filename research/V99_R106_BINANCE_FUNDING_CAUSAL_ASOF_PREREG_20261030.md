# V99 R106 — causal first-party funding as-of adapter preregistration (2026-10-30, before implementation)

**Purpose:** close a real causal integration defect: Binance publisher-verified original `calc_time` can occur 1–31 ms after a nominal 8h funding boundary. Snapping to the earlier nominal boundary could leak the rate into an earlier decision. This is a source-availability *lower-bound* research adapter, **NOT proof of exchange publication time, account-settled funding, a trading signal, economic PnL, or permission to trade**.

## Fixed scope and rules before reading source again

- TRAIN only: hourly decisions `[2021-12-09T00:00Z, 2023-10-01T00:00Z)`, BTCUSDT/ETHUSDT Binance USD-M perpetual. Exactly 15,864 hourly decision clocks per asset, five immutable chronological folds `[0,3172,6345,9518,12691,15864]` hours. No validation/holdout.
- Re-fetch the **same 44 original Binance monthly fundingRate ZIP + publisher CHECKSUM files**; fail closed unless all 44 hashes and CSVs are verified, 1,983 in-TRAIN rows per asset, 8h intervals, unique nominal slots, and all `calc_time` residuals are in `[0,31]` ms. Preserve original timestamp and rate bytes, never shift, round, or replace them.
- At hourly decision `t`, a rate is eligible for **research-only earliest-possible as-of** only if original `calc_time < t`. This is the immediately prior completed hour, not `calc_time <= t`; if an original event occurs exactly at `t`, it is **not** eligible at `t`. A +1–31 ms event also cannot be eligible at its nominal boundary. Prior December source events may warm up the first TRAIN decision. No future events may be read.
- The output is a source-only hourly availability trace, hashed as `sha256(UTF-8 lines of t_ms,original_calc_time_ms,rate_as_original_17g)`, with aggregate five-fold availability, number of nominal-boundary decisions where the current slot is forbidden, and per-symbol digest. Never publish rate rows or claim actual historical public release latency.
- Separate oracle must parse original publisher ZIP/CHECKSUM bytes independently and reconstruct every hourly as-of decision/digest. Deliberately mutated timestamp/early-availability fixture must fail. If source unavailable, fail closed and report the precise missing source.
- This adapter is **optimistic**: `calc_time` is a calculation timestamp, not authenticated dissemination or private settlement. Future economic research must use stricter documented dissemination/settlement as-of evidence, dated native fee tier, fill/size/margin/liquidation evidence, independently modeled severe/supersevere accounting, five TRAIN folds and risk gates before any candidate freeze. Existing exact-clock source gate remains **821/1983**, unchanged; API 451 blocker remains.
- **NO PROMOTION**, no trading strategy, no ROI, no opening sealed validation `[2023-10-01,2024-01-18)` or final holdout `>=2024-01-18`, no Frozen V16/V99, paper/results, champion, dashboard performance or order-interface mutation.

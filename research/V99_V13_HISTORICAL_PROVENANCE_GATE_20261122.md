Status: **BLOCKED / NO PROMOTION**. This note does not certify or repair the published paper.

## Verified source-level invariants
- `scripts/paper_once_v13.py` computes both `order_value_brl` and `order_value_brl_unrounded` from the same `result.asset_order_notional[timestamp,symbol]` through `to_brl(value) = 10000 * value / base_equity`, where `base_equity = result.equity[paper_start]`.
- `scripts/verify_paper_cycle_v13.py` requires `round(raw,2) == displayed` when raw is present. A zero display is only legitimate with finite positive raw < 0.005 and a nonzero weight delta.
- `assert_historical_orders_unchanged` compares historical displayed order amounts, sides, action codes, weights and execution prices; it also compares raw amounts when present in the original. Never bypass this invariant.

## What is NOT established
The archived audit's reported 1,425 missing raw values and 286 raw/display divergences are **not** proof of which generator revision produced each operation. A timestamp-based split cannot identify the writing commit. In particular, do not infer that 270 later-dated divergences were generated by post-change code. Recomputing a historical order using today's `base_equity`, changed data, or a different paper boundary is not evidence of its original executed amount.
